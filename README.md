# Ochi - A creative frontend project
An interactive web experience inspired by [Ochi.design](https://ochi.design/). Built with a focus on smooth scrolling performance and component architecture.
[Live Demo](https://ochi-roan.vercel.app/)
---
### Key Features & Highlights
- **Eye Tracking:** Interactive Eye Tracking feature in the Play and contact section.
- **Smooth Scroll:** Added Smooth Scroll through locomotive.
- **Micro-Interactions & Hover Dynamics:** Added different cool button state transitions.
---
### Development Scope
*Note: This project was built as a desktop-first (laptop) implementation focusing on desktop animation mechanics. Full mobile responsiveness may be added in future updates.*
